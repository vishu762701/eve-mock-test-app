# Bulletin adaptation checkpoint

EVE's bulletin implementation is a source-traced EVE adaptation of the behavior and numeric values supplied by the owner; it is not copied Telegram source and does not claim byte identity or optical parity. The original archive was not available or validated in this environment. Enter and exit use a 400-stiffness, 0.8-damping AndroidX spring; their runtime motion remains subject to device verification. The 8000ms error duration remains an EVE readability adaptation. Informational messages can be replaced or coalesced; actionable messages and errors wait in FIFO order, without a fixed cap so a callback is not silently discarded. Lifecycle destruction clears transient notices without executing callbacks.

The attached-device suite exercises gestures, action and lifecycle behavior, theme changes, a narrow RTL window with enlarged Hindi text, floating-pill clearance and screenshots. IME clearance is explicitly MANUAL/UNKNOWN if the emulator does not provide a visible keyboard. Exact-SHA FULL CI, screenshots and APK evidence must be checked before completion. The host samples inset and pill geometry at pre-draw. A 900-stiffness, no-bounce spring handles downward offset changes; upward changes are immediate to avoid obscuring a newly raised IME or pill. This EVE safety adaptation still requires attached-device verification. The queue, gesture dispatch and accessibility must not be called verified until tests actually run.

For imported palettes, foregrounds are adjusted only when needed against the translucent bulletin fill composited over the theme canvas and surface roles. This approximation cannot prove contrast over arbitrary image pixels; actual-device contrast remains unverified.

EVE uses a vertically scrollable message area when the available viewport is too
short for the full text. Horizontal drags on that area remain bulletin swipes;
vertical drags remain message scrolling. This is an EVE accessibility adaptation
and requires attached-device verification, especially with IME and large fonts.
