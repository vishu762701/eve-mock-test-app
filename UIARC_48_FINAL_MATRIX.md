## Evidence and constraints

- Direct source references were inspected via GitHub file retrieval/search and previous `DECISIONS.md` ADR-022 through ADR-032; the presence of a class is not proof that its animation was exercised or matches upstream physics.
- Real CI provides Android build/lint/unit plus native gesture and three-button gates. A generic JVM/source assertion is **not** a substitute for complete visual or timing parity.
- `UiArcProgressBar.kt` has source/tests but no independently confirmed production caller, so it remains a cleanup candidate, **not** a falsely rendered item.
- The former slider host `TypographyStudioActivity` was expressly retired. All required 48 records are accounted for, but full UIArc upstream motion equivalence is **UNKNOWN** where original JSON assets could not be retrieved.
